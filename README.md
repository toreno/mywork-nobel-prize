# ノーベル賞 受賞者検索

歴代ノーベル賞受賞者を、部門・年・キーワードで検索・絞り込みできる単一ページのWebアプリです。ビルド不要で、ブラウザで `index.html` を開けば動きます。

## 現在の収録範囲

- **2026年 〜 1980年（47年分）** / 全6部門（物理学・化学・生理学医学・文学・平和・経済学）
- 各年・各部門に「受賞者名（日本語＋英語）・国・受賞理由の要約・その年の意義（解説）」を収録
- 受賞理由は Nobel Prize 公式 / Wikipedia 各年ページをもとに**要約・言い換え**（原文のコピーではない）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 検索UI＋表示ロジック（HTML/CSS/JSが1ファイルに同梱）。データは持たない |
| `nobel-data.js` | 受賞データ本体。`window.NOBEL_DATA` という配列を定義 |
| `ノーベル賞_2026-2000.md` | 読み物版（2000年までの解説ドキュメント）。※Markdownは2000年まで。1999〜1980はJSデータにのみ存在 |
| `README.md` | このファイル |

> 注意: `index.html` と `nobel-data.js` の2つが検索ページの実体です。`ノーベル賞_2026-2000.md` は初期に作った読み物で、JSデータとは別物（更新されていません）。

## 画面でできること（index.html）

- **キーワード検索**: 受賞者名・英語名・国・受賞理由を横断検索。一致部分はハイライト
- **部門フィルタ**（チップ）: すべて / 物理学 / 化学 / 生理学・医学 / 文学 / 平和 / 経済学
- **年フィルタ**（セレクト）: 特定の年だけ表示
- **表示モード**: カード / 簡易リスト
- **項目トグル**: 氏名 / 国 / 内容 を個別にオン・オフ（最低1つは残る）
- **単一部門を選ぶと専用ビュー**: 部門名を見出しに「年 ｜ 内容」を縦に並べ、その部門の歴史を一覧できる（`renderCategoryView()`）

## データ形式（nobel-data.js）

`window.NOBEL_DATA` は**降順（新しい年が先頭）**の配列です。1エントリ＝1年。

```js
{
  year: 2024,
  categories: {
    physics:    { laureates: [{ name: "日本語名", en: "English Name", country: "米国" }], reason: "受賞理由の要約" },
    chemistry:  { laureates: [ ... ], reason: "..." },
    medicine:   { laureates: [ ... ], reason: "..." },  // 生理学・医学
    literature: { laureates: [ ... ], reason: "..." },
    peace:      { laureates: [ ... ], reason: "..." },
    economics:  { laureates: [ ... ], reason: "..." }   // 経済学
  },
  note: "その年の意義・トピックの解説（任意だが全年に記載済み）"
}
```

- `laureates` は複数人（共同受賞）に対応する配列。個人でも団体でも1要素で表す
- 団体の場合も `name`/`en`/`country` を埋める（例: `{ name: "日本原水爆被害者団体協議会（日本被団協）", en: "Nihon Hidankyo", country: "日本" }`）
- 複数国籍は `country` に「英国・カナダ」のように併記
- カテゴリのキー名（`medicine` = 生理学医学、`economics` = 経済学）は `index.html` 側の `CAT_LABELS` / `CAT_ORDER` と対応しているので変更しないこと

## データの追加・編集の手順

1. `nobel-data.js` を編集する。年を**遡って追加する場合は配列の末尾**（＝古い年が後ろ）に、降順を保って追記する
2. 既存エントリと同じ形（6部門すべて／`laureates`＋`reason`／`note`）に揃える
3. `node --check nobel-data.js` で構文エラーがないか確認
4. ブラウザで `index.html` を開き、追加した年が表示・検索できるか確認

`index.html` 側は原則さわらなくてよい（データ量に依存しない作りになっている）。

## 続き（1979年以前）に進むときの注意

次に遡るなら **1979〜1970 → 1960年代 … → 1901年** の順がおすすめ。ただし古い年には以下の事情があり、**データ構造とページ側の小改修が必要**になる見込み:

- **経済学賞は1969年開始**。1968年以前は経済学の `economics` カテゴリが存在しない年になる
- **授賞なしの年がある**（例: 戦時中の1940〜1942年など）。部門ごと or 年ごとに「授賞なし」を表現する必要がある
  - 対応案: 該当カテゴリを省略可能にし、`index.html` の `cardHtml`/`listRowHtml`/`renderCategoryView` 側で `entry` が無いときにスキップ or 「授賞なし」表示する分岐を足す
- 1980〜1989はWikipediaの統合年ページ（`/wiki/19XX_Nobel_Prizes`）が無い年がある。公式の10年単位リスト（例: `nobelprize.org/prizes/lists/all-nobel-prizes/1989-1980/`）や各年の集約ページで裏取りした
- 1990年以降は `https://en.wikipedia.org/wiki/19XX_Nobel_Prizes` が使いやすい

## データソース / 裏取りの方針

- 一次情報は [Nobel Prize 公式](https://www.nobelprize.org/)、補助として Wikipedia 各年ページ
- 受賞理由は原文を**要約・言い換え**して記載（長文の逐語コピーは避ける）
- 国籍は受賞時点または主要活動国で記載

## 既知の留意点

- 2025・2026年は発表直後の情報を含むため、公式サイトの確定情報で細部が今後更新される可能性がある
- 1980年代の人名カナ表記は揺れが出やすい（必要に応じて統一・修正の余地あり）
- `ノーベル賞_2026-2000.md` は2000年までで止まっており、検索ページ（JS）とは同期していない。読み物も最新化したい場合は別途追記が必要
